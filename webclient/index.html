OTG Drive Bridge

把手机 OTG U 盘挂进浏览器的 WebDAV 客户端
GitHub 下载 APK / EXE

连接 WebDAV 服务器

地址与用户名来自手机 App「连接方式」卡片；密码在「访问凭据」卡片。浏览器到手机是跨域请求， 手机端服务器需放行 CORS 才能连上——手机自带的同源文件页（直接用浏览器打开 http://手机IP:8080/）不受此限制。演示模式无需任何服务器。
